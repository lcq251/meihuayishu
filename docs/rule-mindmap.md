## 规则优先级

```text
输入与起卦
  → 本卦、动爻、变卦、互卦
  → 体用判定
  → 五行生克
  → 互变与旺衰修正
  → 占问主题规则
  → 象意、外应、应期
  → 保留原文依据和不确定项
```

原文明确要求“不可拘执于一”，因此脑图中的“通常为吉/凶”属于基础倾向，主题规则、旺衰、互变和外应可以修正它。
