# 案例多维对应模型

本模型只抽取案例中的结构、象、义、条件和差异，不生成最终吉凶或事件结论。最终解释必须在占问意图、时间、方位、动静和外应等上下文完整后执行。

## 维度层级

```text
排盘结构 → 卦象维度 → 五行与体用 → 象（人物、物品、身体、方位、声音、颜色）
→ 义（卦辞、爻辞、卦德、主题语义）→ 上下文条件 → 原文推理链 → 模型差异
```

| 维度 | 内容 | 自动化状态 |
|---|---|---|
| 起卦方法 | 时间、声音、字画、物象/方位 | 部分可计算 |
| 输入事实 | 时间、数量、方向、物品、声音 | 抽取或人工确认 |
| 本卦结构 | 上卦、下卦、内卦、外卦 | 可计算 |
| 动爻结构 | 动爻位置、数量、阴阳变化 | 可计算 |
| 变卦/互卦 | 过程和变化结构 | 可计算 |
| 体用 | 主体与所问之事 | 依规则版本 |
| 五行 | 生、克、比和、旺衰 | 部分可计算 |
| 卦象 | 人物、物品、身体、方位、颜色、声音 | 候选匹配 |
| 卦义 | 卦辞、爻辞、卦德、主题语义 | 候选匹配 |
| 上下文 | 时间、季节、动静、场景和用途 | 需要输入 |
| 差异 | 原文与标准模型不一致处 | 需要校勘 |
| 结论 | 本阶段排除 | 不生成 |

## 模型边界

- “卦”描述结构，不直接等于事件。
- “象”提供候选对象，不直接等于唯一对象。
- “义”提供传统语义，需要结合主题和上下文。
- 原文后验结果只作为验证资料，不作为自动推理条件。
- 缺失上下文标记为 `missing`，不填充默认事实。
