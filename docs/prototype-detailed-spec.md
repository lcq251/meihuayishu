# 原型详细设计

## 推导页

### 输入区

- 起卦方法：年月日時、数字、声音、字占、物数。
- 时间：公历或农历；自动显示转换后的干支、节气和时辰。
- 季节：默认自动计算，可手动覆盖。
- 方位：可选；未选择时关闭方位外应规则。
- 动静：行、立、坐、静止；未选择时关闭动静应期规则。
- 解卦意图：一般、婚姻、求财、家宅、出行、天时、健康、物品等。

### 结果区

1. 本卦、动爻、变卦、互卦。
2. 体卦、用卦、五行关系。
3. 规则发现：支持、反对、冲突和置信等级。
4. 推理时间线：每步可折叠。
5. 来源悬浮提示：规则、条件、文件和行号。
6. 传统解释：只由已触发规则和象意生成。

## 原文页

- 三层目录：卷 → 篇 → 章节。
- 章节内容按原文显示，保留繁体。
- 支持标题和关键词搜索。
- 从规则来源可以跳转到对应章节。
- 原文页不重复显示页面标题，目录和正文承担定位功能。

## 知识图谱页

- 第一层节点：八卦、五行、起卦方法、主题规则、案例、原文章节。
- 第二层关系：属五行、使用方法、产生卦象、引用规则、对应案例。
- 支持按节点类型过滤。
- 点击节点打开详情和来源。

## 响应式设计

- 桌面端：左侧上下文和目录，右侧结果或原文。
- 移动端：上下布局，目录折叠为选择器。
- 来源 Tooltip 在移动端改为点击弹层。
