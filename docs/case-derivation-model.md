# 原书案例与推导模型

## 范围与边界

完成卷一十个连续命名案例的逐例建模；卷二、卷三附加案例组保留原文与待校勘状态。此为案例研究模型，不代表穷尽全书每个散见举例，也未接入现有前端引擎。

## 统一推导模型

事实输入 → 占法取数 → 本卦及动爻 → 变卦互卦 → 体用 → 生克与阶段 → 类象候选 → 语境筛选 → 应期假设 → 结论及未决项。

- 确定层：正余数、六爻阴阳、变爻、上下互卦、单动爻体用。
- 条件层：占问对象、五行、旺衰、爻辞与外应，缺信息即停止相关判断。
- 解释层：取象、应期、候选筛选，保留原书理由，不编码成唯一事实。
- 结果层：书中后验记载与推理输入隔离，避免以结果反推规则。

## 校勘与不可直接推广项

- 少年占：按标准互卦为上震下坎，坎水克离火，与“互变俱生之”不完全一致。
- 牛占：互卦上坤下震，坤土比和而非克体，与“互变俱克”不完全一致。
- 加数例：王姓总数27余3，原文却写“余三为初爻”；屋宅段又以22、29、31定年，不能直接统一为前文总数。
- 观物泰卦初变升：标准泰初爻变为升；其标准互卦上震下兑，文中颜色根部取象需要人工解释。
- 鼎变恒的标准变化在第四爻，但引用“鼎玉铉”为上爻辞；保留而不静默修正。
- 乾坤互卦例外应由规则版本明确，本批命名案例不涉及此特例。
