# 案例逐词逐名属性模型

本模型直接读取 `data/case-models.v1.json` 的排盘结果，不重新执行起卦计算。案例原文中的每个关键词、人名、物名、动作和环境词作为属性证据保存，并与卦、象、义、上下文维度关联。

## 分析原则

```text
已有排盘结果
  → 原文词项 / 名称抽取
  → 词项归类
  → 卦象属性匹配
  → 体用与变互关系匹配
  → 主题和语境标签
  → 差异、缺失和冲突
```

- 不从词项反推卦象；卦象以既有排盘结果为准。
- 不把词项对应的象意合并成最终事件结论。
- 同一个词可以有多个候选属性，例如“马”可以是动物、速度、乾卦类象。
- 每个属性都保留原文词、词类、候选卦、来源和证据状态。

## 属性维度

| 维度 | 示例 |
|---|---|
| 人物/名称 | 先生、客、老人、少年、女子、贵官 |
| 动物 | 雀、马、牛、鸡 |
| 植物/物品 | 梅、牡丹、枯枝、斧、锄、牌额 |
| 动作 | 争、坠、折、扣、借、鸣、伐、踐毁 |
| 身体 | 股、口、目、足、腹 |
| 方位 | 南、北、东、西、巽方、乾方、兑方 |
| 时间 | 年、月、日、时、明晚、次日、十日、二十一日 |
| 声音/文字 | 一声、五声、平声、去声、字画、缺勾 |
| 状态 | 盛、悲、喜、忧、静、动、破、无风 |
| 语义 | 吉、凶、阻、助、损、成、迟、速 |
| 来源结果 | 本卦、动爻、变卦、互卦、体卦、用卦 |

## 单词属性结构

```ts
type CaseTermAttribute = {
  term: string
  normalized?: string
  category: string
  role: 'subject' | 'object' | 'action' | 'environment' | 'time' | 'evidence'
  candidateTrigrams?: string[]
  candidateAttributes?: string[]
  sourceLine: number
  evidenceStatus: 'source-explicit' | 'case-inferred' | 'unresolved'
}
```

## 输出边界

页面应展示“词项 → 候选属性 → 排盘关系 → 原文依据”，不直接显示最终预测结论。最终解卦需要另一个步骤接收用户意图、季节、方位、动静和外应。
