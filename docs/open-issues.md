# 待解决问题

## 高优先级

- 确定公历、农历和节气的转换库及测试基准。
- 明确子时换日规则，提供 `子初` / `子正` 配置。
- 补齐六十四卦数据和卦辞、爻辞来源。
- 确认体用判定的规则版本，并覆盖乾坤互卦等例外。
- 将当前 TypeScript 内置规则迁移到配置和插件注册表。

## 中优先级

- 定义主题规则优先级和冲突解决策略。
- 建立规则来源等级：明确规则、主题规则、案例、象意。
- 定义权重含义，避免把权重误解成预测概率。
- 补齐原文段落和章节的稳定 ID。
- 为外应、方位、动静建立人工输入模型。

## 低优先级

- 真太阳时和经纬度修正。
- 多传承规则版本比较。
- 规则编辑器和配置导入导出。
- 图谱节点详情和反向来源查询。

## 产品边界

- 健康、投资、法律等主题只输出传统文本解释，不生成专业决策。
- 缺少上下文时关闭相关规则，不填充虚构默认值。
- 无法消解的冲突必须并列展示，并标注不确定性。
