# 梅花易數推導应用实施计划

## 目标

使用 React + TypeScript 构建一个可复核的梅花易數推导工具：用户输入起卦信息后，系统展示本卦、动爻、变卦、互卦、体用、五行关系、原文依据和相关案例。

## 范围与原则

- 第一版只承诺确定性的数理计算和原文检索，不把传统断语包装成确定事实。
- 规则、解释文本、案例和原文引用分离保存。
- 原始 `book/meihua_yishu.txt` 保持不变；新增结构化资料放在 `data/`，说明文档放在 `docs/`。
- 先实现年月日时占和数字占，再扩展字占、声音占、物数占与知识图谱。

## 阶段计划

1. **规则整理与范围冻结（第 1–2 天）**：完成规则清单、八卦/五行数据、案例验算基线和 `classic-v1` 版本。**已完成**。
2. **规则引擎（第 3–7 天）**：实现取余、动爻、变卦、互卦、体用和推导步骤，并用案例测试。**已完成基础版**：年月日時占、变卦、互卦、推导步骤和 2 个回归测试已实现。
3. **React 主界面（第 2 周）**：实现起卦表单、卦象展示、五行关系和可展开推导链。**基础版已完成**：输入校验、体用关系、六爻图、结构卡片和原文引用均已接入。
4. **原文知识库（第 3 周）**：段落索引、原文引用、全文搜索、主题和案例数据。**MVP 已完成**：已接入规则、占法、案例索引和关键词搜索。
5. **知识图谱（第 4 周）**：建立卦象、五行、规则、案例之间的关系并可视化。**轻量 MVP 已完成**：已提供关系数据、SVG 图谱和关系完整性测试。
6. **解释层与发布（后续）**：模板化解释、回归测试、移动端适配和静态部署。**解释层已完成**：已加入确定性模板、依据展开和不确定性说明。

## 第一阶段验收标准

- 规则有明确来源和版本号。
- 八卦数字、五行、取卦、动爻、互卦规则已结构化。
- 至少 3 个原书案例具有可复核的中间值。
- 原始文本无修改，工作区无意外变更。
