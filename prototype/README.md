# 梅花易数原型设计

本目录保存产品原型、交互说明和模块边界。原型采用宋式古籍风：米白宣纸背景、黛黑正文、朱砂色强调、古铜色辅助。

## 页面原型

```text
梅花易数
以象数观变化，以推导见其理

[ 推导 ] [ 原文 ] [ 知识图谱 ]

推导
├── 起卦输入
│   ├── 起卦方法
│   ├── 时间输入
│   ├── 自动季节
│   ├── 方位选择
│   ├── 动静选择
│   └── 解卦意图
├── 本卦 / 变卦
├── 体用与五行
├── 推导步骤手风琴
├── 规则依据悬浮提示
└── 传统解释与冲突说明

原文
├── 卷
├── 篇
├── 章节
└── 原文阅读区

知识图谱
├── 卦象
├── 五行
├── 起卦方法
├── 主题规则
├── 案例
└── 原文来源
```

## 交互约定

- 任何规则结论都能展开查看条件、结果和原文来源。
- 缺少方位、动静、对象时，不自动猜测；显示未提供状态并关闭相关插件。
- 季节默认由时间自动判断，允许用户覆盖并显示覆盖来源。
- 多条规则冲突时显示冲突卡片，允许选择按主题、时间层级或并列展示处理。
- 原文来源统一使用悬浮提示，移动端使用点击弹层。
